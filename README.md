# Sohail's Portfolio

A responsive portfolio website that can be hosted on GitHub Pages, Vercel, or Netlify.

## Before publishing

- The contact button points to your GitHub profile. You can replace it with your email address.
- Update the project link after adding the Guess the Number code to GitHub.
- Add a headshot, LinkedIn profile, or resume link whenever you are ready.

## Deploy with Vercel

1. Sign in at https://vercel.com using Continue with GitHub.
2. Choose Add New, then Project, and import the Sohail17224/my-portfolio repository.
3. Leave Framework Preset as Other and the build and output settings blank.
4. Select Deploy. Vercel will provide a public vercel.app address and redeploy when you push updates to GitHub.

No build step or package installation is required.
